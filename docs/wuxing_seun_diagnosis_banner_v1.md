# 1. 3년 세운 처방 규격

## 1-1. 설계 원칙

**LLM에게 맡기지 않는다.** 세운 오행과 내 사주의 관계는 **5가지 경우로 끝난다.** 판정은 코드가 하고, 문구는 고정 풀에서 뽑는다. LLM은 **해설 2~3문장만** 붙인다.

이유는 A층 사전과 같다 — 매번 생성시키면 느리고, 비싸고, 무엇보다 **오행 관계를 틀릴 여지가 생긴다.**

## 1-2. 입력 데이터 (엔진에서 이미 나옴)

```
세운 간지        calcYearPillar(year, 6, 15) → 간지 + 오행
대운 간지·구간   chart.daewoon.list[] → 간지, 나이구간, start_year
내 부족 오행     classify.ts 판정 결과
내 과다 오행     동일
```

**⚠️ `scoreYear()`의 점수·yearNotes는 쓰지 않는다.** 사건 뉘앙스 문구가 섞여 사건 예측 금지(§1)를 위반한다.

## 1-3. 🔴 판정 로직 — 5케이스

세운 오행 `Y`, 내 부족 오행 `L`, 내 과다 오행 `X`.

| 케이스 | 조건 | 의미 |
|---|---|---|
| **A. 채워지는 해** | `Y = L` | 부족한 것이 직접 들어온다 |
| **B. 기우는 해** | `Y = X` | 이미 넘치는 것이 더 들어온다 |
| **C. 도움이 오는 해** | `Y 생 L` | 부족한 것을 생해주는 기운이 들어온다 |
| **D. 벌어지는 해** | `Y 극 L` | 부족한 것을 치는 기운이 들어온다 |
| **E. 고른 해** | 그 외 | 특별한 편중 없음 |

**우선순위**: A > B > D > C > E. 둘 이상 해당하면 위쪽을 적용한다.
(예: `Y`가 부족 오행이면서 과다 오행을 생하는 경우 → A로 판정)

## 1-4. 연도별 출력 포맷 (3년 동일)

```
[2026년 병오(丙午)]                          근거 강도 A
├ 들어오는 기운   화(火) — [케이스 판정 결과 한 줄]
├ 올해의 상태     [케이스별 고정 문구 풀에서 1개]
├ 우선 항목       A층 사전에서 3개  (선정 규칙 §1-6)
├ 피할 것         A층 사전 설기·회피 항목에서 2개
└ 한 줄 지침      [케이스별 고정 문구 풀에서 1개]
```

+ **3년을 관통하는 흐름 한 문단** (LLM 생성, 2~3문장)

## 1-5. 케이스별 고정 문구 풀

각 케이스에 **올해의 상태 3개 / 한 줄 지침 3개.** 연도별로 다른 문구가 뽑히도록 결정적 선택(해시)을 쓴다.

### A. 채워지는 해 (`Y = L`)

**올해의 상태**
| # | 문구 |
|---|---|
| 1 | 비어 있던 자리가 저절로 채워지는 해입니다 |
| 2 | 부족했던 기운이 밖에서 들어오는 구간입니다 |
| 3 | 평소보다 수월하게 균형이 잡히는 해입니다 |

**한 줄 지침**
| # | 문구 |
|---|---|
| 1 | 올해는 미뤄둔 것을 꺼내기 좋은 해 |
| 2 | 힘을 덜 들이고도 되는 해, 시작을 여기에 두십시오 |
| 3 | 채우기보다 쓰는 해 |

### B. 기우는 해 (`Y = X`)

**올해의 상태**
| # | 문구 |
|---|---|
| 1 | 이미 많은 기운이 더 들어와 한쪽으로 기우는 해입니다 |
| 2 | 넘치는 쪽이 더 커지는 구간입니다 |
| 3 | 평소의 성향이 유난히 강하게 드러나는 해입니다 |

**한 줄 지침**
| # | 문구 |
|---|---|
| 1 | 올해는 채우기보다 덜어내는 해 |
| 2 | 늘리지 말고 흘려보낼 통로를 만드는 해 |
| 3 | 하던 대로 하면 더 기웁니다. 반대로 한 걸음 |

### C. 도움이 오는 해 (`Y 생 L`)

**올해의 상태**
| # | 문구 |
|---|---|
| 1 | 부족한 기운을 만들어주는 쪽이 들어오는 해입니다 |
| 2 | 직접은 아니지만 간접적으로 보충되는 구간입니다 |
| 3 | 채우려는 노력이 평소보다 잘 먹히는 해입니다 |

**한 줄 지침**
| # | 문구 |
|---|---|
| 1 | 올해는 채우는 일을 시작하기 좋은 해 |
| 2 | 밀어주는 바람이 있을 때 방향을 잡으십시오 |
| 3 | 준비하는 해. 결과는 다음에 옵니다 |

### D. 벌어지는 해 (`Y 극 L`)

**올해의 상태**
| # | 문구 |
|---|---|
| 1 | 부족한 기운을 치는 쪽이 들어와 격차가 벌어지는 해입니다 |
| 2 | 비어 있던 자리가 더 비어 보이는 구간입니다 |
| 3 | 평소 약하던 부분이 유난히 드러나는 해입니다 |

**한 줄 지침**
| # | 문구 |
|---|---|
| 1 | 올해는 벌이기보다 지키는 해 |
| 2 | 보충을 게을리하면 티가 나는 해 |
| 3 | 무리하지 않는 것이 최선인 해 |

### E. 고른 해 (그 외)

**올해의 상태**
| # | 문구 |
|---|---|
| 1 | 특별히 기울지도 채워지지도 않는 해입니다 |
| 2 | 외부 변수가 적어 내 페이스대로 가는 구간입니다 |
| 3 | 큰 흐름 없이 평탄한 해입니다 |

**한 줄 지침**
| # | 문구 |
|---|---|
| 1 | 올해는 습관을 만드는 해 |
| 2 | 조용할 때 기반을 다지십시오 |
| 3 | 눈에 띄는 변화보다 쌓는 쪽이 유리한 해 |

## 1-6. 우선 항목 선정 규칙 (코드)

A층 사전에서 그 해에 **효과가 큰 3개**를 뽑는다.

| 케이스 | 선정 기준 |
|---|---|
| A | 부족 오행 보충 항목 중 **강도 A·B 우선** — 효과가 확실한 것부터 |
| B | **과다 오행 설기 항목 우선** (보충보다 설기) |
| C | 부족 오행 보충 항목 중 **행동·환경 축 우선** — 습관화가 잘 되는 시기 |
| D | 부족 오행 보충 항목 중 **강도 A 우선** + 과다 회피 항목 1개 포함 |
| E | 부족 오행 보충 항목 중 **행동 축 우선** — 루틴 정착 |

**피할 것 2개**는 각 오행 사전의 회피 항목(`~줄이기`, `~회피`)에서 뽑는다.

## 1-7. 대운 전환점 표기

`daewoon.list[].start_year`로 3년 창 내 교체 여부를 판정한다.

**⚠️ 완충 표기 필수** — `approxDaewoonStart()`가 근사식이라 ±1~2년 오차가 있다.

| 상황 | 표기 |
|---|---|
| 3년 창에 교체 없음 | 대운을 배경으로만 언급. "지금은 ○○(간지) 대운 안입니다" |
| 3년 창에 교체 있음 | **"○○세 무렵 대운이 ○○(간지)로 바뀝니다"** — 특정 연도를 못 박지 말 것 |

## 1-8. 🔴 금지 사항

- **사건 예측 금지.** 재물·연애·이직·건강 사건의 발생을 말하지 말 것. "무엇을 채우고 덜어내는가"만 다룬다
- `scoreYear()`의 `yearNotes` 문구를 그대로 쓰지 말 것
- 대운 전환 연도를 특정하지 말 것
- 위 고정 문구 풀 외의 지침 문구를 **임의 생성하지 말 것**

# 2. 한 줄 진단 문구

리포트 최상단. **굵은 1문장 + 2문장 보충.**

## 2-1. 형식 규칙

```
**[과다 오행]가 넘치고 [부족 오행]가 비어 있는 사주**
[보충 2문장 — LLM 생성]
```

**⚠️ 해당 명식 고유일 것.** 범용 문장이 검출되면 재생성한다.

## 2-2. 유형별 골격 (LLM 프롬프트에 주입)

| 유형 | 굵은 한 줄 골격 | 예시 |
|---|---|---|
| **부족 1개** | `**[X]가 넘치고 [L]가 비어 있는 사주**` | 화가 넘치고 수가 비어 있는 사주 |
| **부족 2개(편중형)** | `**[L1]와 [L2] 두 자리가 비어 있는 사주**` | 수와 금 두 자리가 비어 있는 사주 |
| **극단형** | `**[X] 하나로 강하게 모인 사주**` | 목 하나로 강하게 모인 사주 |
| **부족 없음** | `**다섯 기운이 고르게 갖춰진 사주**` | — |

## 2-3. 보충 2문장 규칙

1문장: **명식 근거** — 오행 개수·월지·일간을 인용해 왜 그렇게 판정했는지
2문장: **B층 관계** — 그 결핍이 이 사람에게 무엇을 뜻하는지 (식상/인성/재성/관성/비겁)

**예시** (검증용, 실제는 LLM 생성)

> **화가 넘치고 수가 비어 있는 사주**
> 여덟 글자 중 화가 셋인데 수는 표면에 하나도 없고, 진토(辰) 안에 계수가 숨어 있을 뿐입니다. 금(金) 일간에게 수는 내보내는 통로에 해당하므로, 쌓는 힘은 강한데 밖으로 흘려보낼 배관이 얇은 구조입니다.

## 2-4. 금지

- 성격·직업·연애 단정 금지 (티어 경계)
- "노력하면 좋아집니다" 류 범용 문장
- 사건 예측

# 3. `/guide/fill-*` 배너 문구

5편 하단 CTA. **오행명만 치환**되고 나머지는 공통이다.

## 3-1. 확정안

```
┌─────────────────────────────────────────┐
│  이 글은 [수]를 채우는 일반적인 방법입니다   │
│                                         │
│  당신에게 정말 [수]가 부족한지,            │
│  부족하다면 올해 무엇부터 해야 하는지는     │
│  생년월일이 있어야 알 수 있습니다.          │
│                                         │
│  [ 내 사주로 확인하기 · 990원 ]            │
└─────────────────────────────────────────┘
```

**치환**: `[수]` → 각 글의 오행명 (수·화·목·금·토)

## 3-2. 설계 의도

**무료 글을 깎지 않는다.** "이 글은 부실합니다"가 아니라 **"이 글은 일반론이고, 당신 이야기는 따로 있습니다"**로 간격을 정확히 짚는다.

5편 전부가 이미 **"부족하다고 무조건 채우는 것은 아니다"**라는 단서를 달아뒀다. 이 배너는 **그 글이 던진 질문에 상품이 답하는 구조**다 — 무료 글이 "당신에게 정말 필요한지는 용신을 봐야 안다"고 했고, 배너가 "그걸 확인해 드립니다"라고 받는다.

## 3-3. 보조 문구 (선택)

배너가 광고로만 읽히지 않게, 버튼 아래 작은 글씨로:

```
부족 여부 판정 · 3년 세운 처방 · 어떤 사람이 맞는지까지
```

이 세 가지가 **무료 글에 없는 것**이며, 990원의 값이다.
