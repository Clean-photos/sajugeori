## 0. 공통 규격

**A층 사전**이므로 일간과 무관한 **오행 자체의 속성**만 다룬다. "채워졌을 때 나에게 무슨 일이 일어나는가"는 B층(관계 레이어)이 담당한다.

**축 구성 (6축)**: 색 / 방위·공간 / 음식·맛 / 소재·물건 / 행동·루틴 / 환경
※ 사람·관계 축은 B층 §3으로 이관됨

**근거 강도**
- **A** — 오행 배속에서 직접 도출, 이견 거의 없음
- **B** — 배속 + 통용 해석의 결합, 유파별 강조점 차이 가능
- **C** — 개운·환경 처방. 전통 내 통용, 개인차 크고 과학적 검증 없음

**전 항목 공통 고지**: 개운법은 전통 안에서 통용되는 방식이며, 과학적으로 검증된 것은 아니다.

**보조 오행 원리**: 부족한 오행을 직접 채우는 것 외에, **그 오행을 생해주는 오행**을 함께 쓰면 효과가 안정적이다. (목 부족 → 수가 목을 생함 / 화 부족 → 목 / 토 부족 → 화 / 금 부족 → 토 / 수 부족 → 금)
