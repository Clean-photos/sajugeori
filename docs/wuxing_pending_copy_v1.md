# 1. §② 도입 서술 — "무조건 채우는 게 아니다"

**위치**: 오행 지도 섹션 최상단, 오행 분포 막대보다 앞.

**근거**: `/guide/fill-*` 5편 전부가 "부족하다고 무조건 채워야 하는 건 아니다, 용신에 따라 다르다"는 단서를 달아뒀다. 무료 글이 던진 질문에 유료 상품이 답하는 구조.

## 1-1. 고정 도입문 (전 유저 공통)

> 사주에 어떤 기운이 적다고 해서 무조건 채워야 하는 것은 아닙니다. 그 사람에게 실제로 필요한 기운이 무엇인지에 따라 답이 달라지며, 이 리포트는 그 판정부터 시작합니다.

## 1-2. 판정 결과 연결문 (조건 분기, 코드가 선택)

| 조건 | 연결문 |
|---|---|
| primary = 용신 (일치) | 구조적으로 부족한 기운과 명리학적으로 필요한 기운이 같습니다. 아래 처방은 두 관점 모두에서 일치하는 결과입니다. |
| primary ≠ 용신 (불일치) | 구조적으로 부족한 기운과 명리학적으로 필요한 기운이 다르게 나왔습니다. 아래 처방은 이 차이를 함께 안내합니다. |
| 극단형 | 이 사주는 한 기운으로 강하게 모인 구조입니다. 이런 경우 부족한 것을 채우기보다 흐름을 따르는 편이 명리학적으로 더 유효합니다. |
| 부족 없음 (이론상 미도달, 방어용) | 여덟 글자에 뚜렷한 결핍이 보이지 않습니다. 아래는 채우기보다 흐름을 관리하는 처방입니다. |

# 2. 억부·조후 충돌 안내

**위치**: §② 용신 카드 하단, 또는 §③ 본체 진입 직전.

**발동 조건**: 억부 후보와 조후 후보의 교집합이 없을 때 (결정①-교집합 없음 케이스).

## 2-1. 고정 문구

> 이 사주는 몸을 보강하는 관점(억부)과 계절의 온도를 맞추는 관점(조후)이 서로 다른 기운을 가리킵니다. 두 관점이 갈리는 것은 흔한 일이며, 이 리포트는 조후를 우선하고 억부를 보조로 함께 제시합니다.

## 2-2. 표 형태 병기 (선택 — 렌더 여백에 따라)

```
[주 처방 · 조후]  ○○(오행)
[보조 참고 · 억부] ○○(오행)
```

**금지**: 단일 용신으로 단정하지 말 것 (기획 §2 원칙 유지). "정답은 하나입니다" 류 표현 금지.

# 3. 극단형 처방 안내

**위치**: §③ 본체 최상단, 일반 처방(채우기) 대신 노출.

**발동 조건**: 유형 분기 C(한 오행 5개 이상). 시간 미상 사주에는 이 분기 자체가 발동하지 않음(기존 결정 유지).

## 3-1. 도입 문구

> 당신의 사주는 [강한 오행]이 유난히 강하게 모인 구조입니다. 이런 사주는 부족한 기운을 억지로 채우기보다, 강한 흐름을 따라가는 쪽이 명리학적으로 더 안정적입니다. 넘치는 기운을 누르려 하면 오히려 반발이 커질 수 있습니다.

## 3-2. 처방 방향 문구 (강한 오행별 5종 — 강한 오행이 생하는 방향)

| 강한 오행 | 순응 방향 문구 |
|---|---|
| 목(木) | 목의 흐름을 살려 화(火) 방향으로 흘려보내는 것이 유효합니다. 벌이는 일을 마무리까지 끌고 가는 데 집중해 보십시오. |
| 화(火) | 화의 흐름을 살려 토(土) 방향으로 흘려보내는 것이 유효합니다. 발산한 것을 결과물로 남기는 데 집중해 보십시오. |
| 토(土) | 토의 흐름을 살려 금(金) 방향으로 흘려보내는 것이 유효합니다. 쌓아온 것을 정리하고 기준을 세우는 데 집중해 보십시오. |
| 금(金) | 금의 흐름을 살려 수(水) 방향으로 흘려보내는 것이 유효합니다. 단단한 기준을 유연하게 표현하는 데 집중해 보십시오. |
| 수(水) | 수의 흐름을 살려 목(木) 방향으로 흘려보내는 것이 유효합니다. 생각한 것을 실제로 시작하는 데 집중해 보십시오. |

**우선 항목 선정**: 각 오행 사전의 §7(과다 시 설기) 항목을 그대로 사용. 신규 항목 불요 — 이미 A층 사전에 있음.

**금지**: 극하는 오행 관련 항목(채우기 방향)을 노출하지 말 것 (§3-B-④ 원칙).

# 4. primary↔용신 충돌 안내 (본체 진입부)

**위치**: §③ 본체 시작, "채우는 법" 타이틀 직후.

**발동 조건**: primary ≠ 용신.

## 4-1. 고정 문구

> 구조적으로 채워야 할 자리는 **[primary 오행]**이지만, 명리학적으로 균형을 위해 필요한 기운(용신)은 **[용신 오행]**입니다. 아래 처방은 [primary 오행] 기준으로 구성되어 있으며, 용신 관점은 §② 용신 카드를 함께 참고해 주십시오.

## 4-2. 일치 시 (대조군, 발동 조건 아니지만 완결성을 위해)

> 구조적으로 채워야 할 자리와 명리학적으로 필요한 기운이 **[오행]**으로 일치합니다. 아래 처방은 두 관점 모두에서 뒷받침되는 결과입니다.

# 5. 톤 공통 규칙

- 전부 존댓말 (D30-③)
- 단정 대신 "~한 편이 유효합니다", "~로 보입니다" 톤 유지
- 억부·조후·primary·용신 **넷 중 어느 것도 "틀렸다"고 말하지 않는다.** 관점의 차이로만 서술
- 개운법 위상 고지(전통 내 통용, 과학적 검증 없음)는 이 4종 문구에는 반복하지 않는다 — 마무리 섹션(§⑦)에서 1회 고지로 충분. 매 섹션 반복하면 상품이 스스로를 계속 의심하는 톤이 되어 신뢰를 깎는다

# 6. Dev 반영 요청 사항

1. §1-2 연결문은 **코드 분기**(primary=용신 / 불일치 / 극단형 / 부족없음)로 자동 선택
2. §2는 **억부·조후 교집합 없음 조건에서만** 렌더, 있으면 미노출
3. §3은 **극단형 판정 시에만** §③ 본체를 이 블록으로 **대체** (일반 채우기 처방 대신)
4. §4는 **primary≠용신 조건에서만** 노출, 일치 시 §4-2 짧은 문구로 대체
5. 오행명 치환 토큰(`[primary 오행]`, `[용신 오행]`, `[강한 오행]`)은 기존 relation.json 인트로 템플릿과 동일한 치환 방식 사용
